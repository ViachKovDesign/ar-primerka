    6Добавить в каталог

    Как опубликовать

    1. Распакуйте скачанный архив. Внутри — папка na-sait (в ней catalog.json, models/, posters/) и файл с инструкцией.
    2. Откройте папку na-sait и выделите в ней всё (Ctrl+A).
    3. Откройте репозиторий на GitHub → Add file → Upload files.
    4. Перетащите выделенное мышкой в окно GitHub. В списке должны быть пути с папками: models/…/….glb, posters/….webp. catalog.json заменится, новые модели добавятся.
    5. Внизу нажмите Commit changes. Через 1–2 минуты товар появится на сайте.

    Не выбирайте файлы через окно «choose your files» — GitHub потеряет папки, модели окажутся в корне и сайт их не найдёт. Сам ZIP и файл инструкции на сайт не загружайте.

    Если работаете через git: скопируйте содержимое папки na-sait в папку проекта, затем git add ., git commit, git push.
