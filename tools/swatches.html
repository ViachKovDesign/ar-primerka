Кружки по рендеру

Служебная страница (локально: npm run serve → /tools/swatches.html). Рендерит каждый вариант каталога при нейтральном свете той же камерой, что окно виджета, и берёт средний цвет освещённой ткани (js/swatch-render.js). Результат — tools/swatch-renders.json: по нему тест npm test проверяет кружки в catalog.json. Если модель поменялась — откройте страницу, скачайте файл и положите его в tools/.
