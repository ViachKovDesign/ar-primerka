# Требования к 3D-моделям для AR-каталога

Документ для 3D-дизайнеров и поставщиков. Модель, которая им соответствует, откроется на iPhone (Quick Look), на Android (Scene Viewer и WebXR) и в браузере без доработок. Админка проверяет эти правила автоматически.

## 1. Формат

| Требование | Значение |
|---|---|
| Файл | **GLB** (glTF 2.0, бинарный), один файл, всё внутри — без внешних .bin и картинок |
| Валидность | **0 ошибок** в [Khronos glTF Validator](https://github.khronos.org/glTF-Validator/). Предупреждения допустимы. Scene Viewer не открывает файлы с ошибками |
| Анимации, скелеты, камеры, источники света | Не включать |
| Сжатие | **Без** Draco, meshopt (`EXT_meshopt_compression`), KTX2/Basis, WebP-текстур: их не открывает Scene Viewer, а KTX2 ломает USDZ для iPhone |

## 2. Размер и положение

| Требование | Значение |
|---|---|
| Единицы | **Метры, 1 единица = 1 м.** Кресло шириной 85 см → 0.85 по X. Допуск ±1 см к реальным габаритам |
| Оси | Y — вверх, перед предмета смотрит на +Z |
| Точка опоры (origin) | **Центр низа** предмета: ножки стоят на y = 0. Для настенных — центр задней плоскости |
| Трансформации | Применены (масштаб 1, поворот 0 у корневого объекта) |

## 3. Сложность и вес

| Параметр | Рекомендуется | Максимум |
|---|---|---|
| Треугольники | ≤ 50 000 | 100 000 |
| Материалы | ≤ 5 | 10 |
| Размер текстур | 1024–2048 px, стороны — степени двойки | 2048 px |
| Вес файла | ≤ 5 МБ | 10 МБ (больше — долго грузится на телефоне) |
| UV-развёртка | 1 набор (`TEXCOORD_0`), без перекрытий там, где есть запечённые тени | — |

## 4. Материалы

- PBR Metallic-Roughness (стандарт glTF): base color, metallic/roughness (ORM), normal map. AO — по желанию.
- Текстуры: **JPEG** (цвет, ORM, нормали); **PNG** — только если нужна прозрачность.
- **Цвет варианта должен быть в текстуре (запечён), а не задаваться оттенком поверх текстуры** (base color factor). Иначе на iPhone в AR будет исходный цвет. Для материалов без текстуры (однотонный пластик, металл) достаточно цвета материала.
- Без процедурных и нодовых материалов из Blender/3ds Max — только запечённые текстуры.

## 5. Варианты цвета и ткани

Подходят два способа:

**А. Один файл с вариантами (предпочтительно)** — расширение `KHR_materials_variants`. В Blender: glTF-экспорт → Material Variants.
- Имена вариантов латиницей, строчными, через дефис: `linen-grey`, `velvet-emerald`, `oak-natural`.
- Вариант по умолчанию — первый в списке.

**Б. Отдельный файл на каждый вариант** — с одинаковой геометрией и положением.

В обоих случаях админка сама сделает отдельные файлы на каждый вариант: этого требует Android Scene Viewer.

## 6. Имена файлов и что прислать

```
<артикул>__<вариант>.glb      например  mira-chair__linen-grey.glb
<артикул>.glb                 если файл с вариантами (способ А)
```

Только латиница, цифры и дефис; два подчёркивания разделяют артикул и вариант.

В комплекте:
1. GLB-файл(ы).
2. Таблица: артикул, название, габариты Ш×Г×В в см, названия вариантов по-русски и их HEX-цвета для кружков выбора.
3. Скриншот модели или фото товара для сверки.

## 7. Самопроверка перед отправкой

- [ ] Открыть файл в https://modelviewer.dev/editor/ — видно целиком, цвета правильные, предмет стоит «на полу».
- [ ] [glTF Validator](https://github.khronos.org/glTF-Validator/) — 0 ошибок.
- [ ] Габариты в метрах совпадают с реальными (в Blender: панель N → Dimensions).
- [ ] Вес ≤ 10 МБ, треугольников ≤ 100 000, текстуры ≤ 2048 px.
- [ ] Нет Draco, meshopt, KTX2 и WebP.
