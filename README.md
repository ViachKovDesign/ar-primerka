# Примерка мебели в AR — прототип

Статический сайт на Google `<model-viewer>`. В каталоге 4 предмета, у каждого 3D-просмотр, 4 варианта цвета и кнопка «Посмотреть в комнате»: на iPhone открывается Quick Look, на Android — WebXR или Scene Viewer. На компьютере вместо кнопки показывается QR-код. Подробный план и чек-лист проверки — в [PLAN.md](PLAN.md), лицензии — в [CREDITS.md](CREDITS.md).

## Запуск на компьютере

```bash
npm install
```

```bash
npm run serve
```

Откройте http://localhost:8080. Чтобы проверить AR, нужен https — см. раздел про GitHub Pages ниже.

## Пересборка (не обязательна: готовые файлы уже лежат в `models/`, `posters/`, `vendor/`)

```bash
npm run fetch
```

```bash
npm run build
```

- `fetch` скачивает исходные модели Poly Haven (1k) в `sources/` (папка в git не попадает).
- `build` копирует библиотеки в `vendor/`, собирает 16 GLB-вариантов и проверяет вес каждого (≤ 3 МБ).
- Постеры каталога: при запущенном `npm run serve` откройте http://localhost:8080/tools/posters.html и дождитесь надписи `done`.

## Как устроено

| Где | Что |
|---|---|
| `index.html`, `css/style.css` | Одна страница: каталог и карточка (`?item=chair&v=graphite`) |
| `js/catalog.js` | Предметы, размеры, варианты, режимы AR |
| `js/app.js` | Смена вариантов, кнопка AR, QR, подсказки, если AR недоступен |
| `models/<предмет>/<вариант>.glb` | По одному файлу на вариант, цвет запечён в файл |
| `scripts/` | Сборка моделей (Node), на сайт не влияет |

Почему отдельный GLB на каждый цвет:
- Scene Viewer открывает файл по ссылке и не видит, что цвет поменяли на странице.
- Quick Look получает USDZ, который model-viewer создаёт на лету из текущего GLB, а оттенок поверх текстуры в USDZ не переносится.

Если цвет запечён в файл, он верный во всех трёх режимах.

### Вес моделей

| Предмет | GLB (скачивается) | USDZ (собирается на iPhone в момент нажатия) |
|---|---|---|
| Кресло | 0.67–0.72 МБ | ~5.3–5.7 МБ |
| Журнальный стол | 0.57–0.61 МБ | ~3.2–3.6 МБ |
| Торшер | 0.05 МБ | ~0.2 МБ |
| Настольная лампа | 0.15 МБ | ~0.5 МБ |

USDZ не скачивается по сети: его делает сам браузер (текстуры внутри — PNG, поэтому файл больше GLB). Если на iPhone это окажется медленно или неточно, есть план B из PLAN.md §4: заранее собранные `.usdz` и атрибут `ios-src`.

## Публикация на GitHub Pages

Только после отдельного подтверждения — порядок шагов в PLAN.md §7. Файл `.nojekyll` отключает обработку сайта Jekyll на Pages, и файлы отдаются как есть.
