# Примерка мебели в AR — прототип

Статический сайт на Google `<model-viewer>` и админка для магазина.
- **Покупатель:** каталог → карточка → вариант цвета → «Посмотреть в комнате». На iPhone открывается Quick Look, на Android — собственный WebXR-режим, на компьютере вместо кнопки показывается QR-код.
- **Магазин:** `admin.html` — загрузить GLB, проверить и исправить, нарезать варианты, скачать ZIP для сайта.

План и чек-листы — в [PLAN.md](PLAN.md), требования к моделям — в [MODEL-SPEC.md](MODEL-SPEC.md), лицензии — в [CREDITS.md](CREDITS.md).

## Запуск на компьютере

```bash
npm install
```

```bash
npm run serve
```

Сайт: http://localhost:8080, админка: http://localhost:8080/admin.html. Чтобы проверить AR, нужен https — см. раздел про GitHub Pages ниже.

## Как устроено

| Где | Что |
|---|---|
| `catalog.json` | Каталог: товары, цены, категории (`floor` / `table` / `wall`), размеры, варианты и пути к моделям. Его выгружает админка |
| `models/<товар>/<вариант>.glb` | По одному файлу на вариант, цвет запечён в файл |
| `posters/<товар>.webp` | Картинки для каталога |
| `index.html`, `js/app.js` | Сайт: каталог с фильтром, карточка, AR, QR, подсказки, отладка `?debug=1` |
| `js/catalog.js` | Загрузка `catalog.json` и правила по категориям (куда ставить, подсказки) |
| `js/xr-ar.js` | Собственный WebXR-режим (Android): кольцо-указатель по hit-test, постановка по касанию, якорь, масштаб 1:1, тень, поворот, пол / стол / стена |
| `admin.html`, `js/admin.js`, `css/admin.css` | Админка (работает только в браузере, без сервера) |
| `vendor/` | Локальные копии библиотек: model-viewer, three.js, qrcode, `admin-libs.js` (glTF-Transform, валидатор Khronos, meshoptimizer, fflate) |
| `scripts/` | Сборка (Node), на сайт не влияет |

Почему отдельный GLB на каждый цвет:
- Android Scene Viewer открывает файл по ссылке и всегда показывает материал по умолчанию: выбранный вариант ему не передать.
- Quick Look получает USDZ, который model-viewer создаёт из текущего GLB, а оттенок поверх текстуры в USDZ не переносится.

Если цвет запечён в файл, он верный во всех режимах. Админка сама нарезает файл с `KHR_materials_variants` на отдельные GLB.

### Режимы AR

| Устройство | Что открывается |
|---|---|
| Android (Chrome с ARCore) | Собственный WebXR-режим (`js/xr-ar.js`). Если не открылся — model-viewer: его WebXR, затем Scene Viewer |
| iPhone / iPad (Safari) | Quick Look, USDZ собирается из текущего GLB |
| Компьютер | QR-код на эту же карточку |

Отладка: добавьте к адресу `?debug=1` (например `…/?item=chair&debug=1`). Под кнопкой AR появится панель с ar-status, canActivateAR, выбранным режимом и журналом событий, а внутри AR — строка состояния hit-test.

## Админка: добавить товар

1. Откройте `admin.html` и перетащите `.glb`. Несколько файлов — это по файлу на вариант (`артикул__вариант.glb`).
2. Проверьте таблицу «✓ / ⚠ / ✗» и включите нужные исправления:
   - единицы модели (м, см, мм, дюймы, «по известной высоте»);
   - поворот;
   - точка опоры;
   - текстуры ≤ 2048 px;
   - упрощение сетки;
   - удаление анимаций.
3. Выберите, откуда брать варианты: из файла, по файлу на вариант, один вариант или «добавить цвета вручную».
4. Посмотрите превью (можно поставить рядом человека 175 см) и проверьте сборку USDZ для iPhone.
5. Заполните карточку и нажмите «Добавить в каталог и скачать ZIP».
6. Распакуйте ZIP и загрузите содержимое в репозиторий: GitHub → Add file → Upload files → Commit. Инструкция лежит внутри архива.

Правка цен и названий, удаление товаров — в блоке «Каталог», затем «Скачать catalog.json».

## Пересборка (не обязательна: готовые файлы уже лежат в репозитории)

```bash
npm run fetch
```

```bash
npm run build
```

- `fetch` скачивает исходные модели Poly Haven (1k) в `sources/` (в git не попадает).
- `build`:
  - копирует библиотеки в `vendor/` и собирает `vendor/admin-libs.js` через esbuild-wasm;
  - собирает 16 GLB-вариантов демо-каталога;
  - проверяет вес моделей;
  - прогоняет glTF-валидатор Khronos (сборка падает при ошибках).
- Постеры демо-каталога: при запущенном `npm run serve` откройте http://localhost:8080/tools/posters.html и дождитесь надписи `done`.
- Тестовые модели для админки, в том числе специально «сломанные» (в см, в мм, с meshopt, с WebP, 250 тыс. треугольников, с вариантами, настенная): `node scripts/make-test-assets.mjs` → `test-assets/` (в git не попадает). Если Node не может скачать зеркало с Poly Haven, скачайте его файлы curl'ом в `test-assets/src/` (код скрипта подскажет имена).
